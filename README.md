# 📊 Customer Churn Prediction

An end-to-end Machine Learning project that predicts whether a customer is likely to churn based on their demographic, account, and service-related information.

This project covers the complete Machine Learning workflow, including data preprocessing, exploratory data analysis, feature scaling, model training, evaluation, model serialization, and an interactive Streamlit prediction application.

---

## 🚀 Project Overview

Customer churn is one of the major challenges faced by subscription-based businesses.

When customers stop using a company's services, businesses lose recurring revenue and also have to spend additional resources acquiring new customers.

The objective of this project is to develop a Machine Learning model that can identify customers who are more likely to leave a service.

The trained model takes customer information as input and predicts whether the customer is likely to churn or stay.

### Prediction Output

🟢 **Customer is likely to stay**

🔴 **Customer is likely to churn**

The trained Machine Learning model and feature scaler are saved using Pickle and loaded by the Streamlit application to generate real-time predictions.
